# Proyecto Semestral: Análisis de Factores de Rendimiento Estudiantil (IMT2200)

## Descripción General

Este repositorio contiene el desarrollo del proyecto semestral para el curso **IMT2200 – Introducción a la Ciencia de Datos**. El objetivo es aplicar un proceso completo de ciencia de datos para responder una pregunta relevante y accionable: **¿Qué factores afectan directamente al desempeño en los exámenes del estudiantado?**

A través del análisis de datos, la construcción de modelos predictivos y la comunicación de resultados, buscamos identificar los principales predictores del rendimiento académico para generar recomendaciones útiles para familias, estudiantes e instituciones.

## Pregunta de Investigación y Objetivos

La pregunta central que guía este proyecto es:

> **¿Qué factores afectan directamente al desempeño en los exámenes del estudiantado?**

Para abordarla, el análisis se divide en cuatro ejes temáticos principales:

1. **Esfuerzo Académico:** ¿Cómo influyen las horas de estudio, la asistencia y el rendimiento previo?
2. **Calidad Socioeconómica:** ¿Cómo el ingreso familiar, la educación de los padres y el tipo de escuela impactan el desempeño?
3. **Bienestar Físico y Conductual:** ¿Cuál es el impacto de los hábitos de sueño, la actividad física y la motivación?
4. **Apoyo y Recursos Educativos:** ¿Cómo se asocian las tutorías, la calidad docente y el acceso a recursos con los resultados académicos?

La **audiencia objetivo** del proyecto son las familias, los propios estudiantes y las instituciones académicas.

## Fuente de Datos

El proyecto utiliza el dataset **"Student Performance Factors"**, obtenido de la plataforma pública **Kaggle**.

- **Nombre:** `StudentPerformanceFactors.csv`
- **Formato:** CSV (Valores Separados por Comas)
- **Tamaño:** Aproximadamente 6,607 registros de estudiantes.
- **Variables:** 20 columnas que abarcan factores de contexto del alumno, contexto escolar, conductuales y demográficos.
- **Link:** https://www.kaggle.com/datasets/fares279/student-performance-factors/

El dataset original se encuentra en `data/raw/` y el dataset limpio, generado por nuestro pipeline, en `data/processed/`.
